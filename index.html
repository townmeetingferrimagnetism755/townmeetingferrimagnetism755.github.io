🎯 What This Tool Does For You

Writing a first draft is slow. Finding papers is slower. Catching a fake reference before a reviewer catches it can be the slowest and most stressful part of all. This application automates those three chores in one continuous flow.

  • Topic in, draft out. You type a research topic. The pipeline produces a paper-shaped draft with an introduction, related work, method discussion, and a conclusion.
  • Grounded in real literature. Sources are pulled from actual published records rather than invented from thin air.
  • Citation hallucination detection. Every reference is checked against real records so fabricated authors, titles, and years are flagged instead of silently passed through.
  • Claim-support checking. Each major claim in the draft is compared with its cited source to see whether the source genuinely backs the statement.
  • Multi-agent pipeline. Separate workers handle searching, outlining, drafting, and verification, so the output stays organised instead of one long messy blob.

✨ Main Features

Literature discovery

The tool searches academic sources related to your topic and builds a working bibliography before any writing begins. That ordering matters: real sources first, prose second.

Draft generation

Sections are written one at a time and stitched into a coherent document. You get a draft you can edit, not a final submission. Treat it as a strong starting point that saves you hours of blank-page time.

Hallucination detection for citations

Each reference is verified. If a paper cannot be found, or the details do not match, it is marked so you can remove or replace it. This is the feature that saves you from the most embarrassing kind of mistake.

Claim-support checking

Sentences that lean on a citation are examined to see whether the cited work actually supports them. Weak or mismatched support is surfaced so you can rewrite or re-cite.

Simple web interface

The application runs locally on your machine and opens in your normal web browser. There is nothing to learn beyond typing a topic and clicking a button.

🚀 Your First Paper in Five Steps

  1. Enter a topic. Type something specific, such as a narrow research question rather than a single broad word. Specific topics produce far better literature matches.
  2. Start the run. Press the main action button. The pipeline begins searching and will show progress as it moves through its stages.
  3. Wait for the search stage. The tool collects real publications first. This stage can take a few minutes depending on how much literature exists.
  4. Watch verification happen. Citations are checked for invented details, and claims are compared against their sources. Items that fail are flagged in the report.
  5. Read the draft and the flags. Open the generated draft, then review the verification notes. Replace or remove any flagged references before you use the text.

Expect your first run to be slower than later ones. Cached literature records make repeat topics noticeably faster.

🔍 Understanding the Verification Report

The report is the most useful part of the output, and it is written to be read by a person rather than a machine.

  • Verified means the reference matches a real publication record and the cited claim appears supported.
  • Unverified means the tool could not confirm the reference. Treat it as suspect and check it yourself.
  • Mismatch means the reference exists but does not appear to support the sentence citing it. Rewrite the sentence or find a better source.
  • Missing support means a claim is asserted without an adequate citation attached.

📋 Practical Tips

  • Start narrow. A focused question returns better-matched literature than a broad field name.
  • Run the same topic twice if the first draft feels thin. Different sources often surface on a second pass.
  • Keep the verification report beside the draft while you edit so you can fix issues in one sitting.
  • Save your draft as soon as it appears, before starting another run.
  • Always open at least a few of the cited papers yourself. Automated checks are a safety net, not a substitute for reading.
